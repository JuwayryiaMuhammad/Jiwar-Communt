# 0026 — Continuous integration

**Status:** Accepted · Phase 4

## Context
Until Phase 3 every check (lint, build, unit and e2e tests, the OpenAPI contract) ran only on a developer machine. The gate domain adds concurrency and immutability guarantees that are worth nothing if a change can merge without running them.

## Decisions
- **One workflow, one job** (`.github/workflows/ci.yml`), on every pull request and every push to `main`. A newer run on the same ref cancels the older one.
- **The real infrastructure, not mocks.** Service containers run the images of `docker-compose.yml` on the same ports: `postgres:17` (5435), `redis:7` (6381), `axllent/mailpit` (1025, 8025). The e2e suites therefore run exactly as locally: RLS as `jiwar_app`, the immutability triggers, OTP codes read from Mailpit.
- **Roles from `docker/postgres/init.sql`.** Service containers start before the checkout, so the script cannot be mounted into `docker-entrypoint-initdb.d`; a step pipes it into `psql` inside the container, with the two role passwords in that process's environment so `\getenv` works unchanged. One script, one source of truth.
- **No secrets.** `.env` is a copy of `.env.example`; every value the workflow uses is a development test value. The workflow has `contents: read` only.
- **Steps, in deploy order:** install with the frozen lockfile (which runs `prisma generate`), `prisma migrate deploy` as the migrator, `access:sync`, then `lint:check` (ESLint without `--fix`, so formatting drift fails instead of being rewritten), `build`, unit tests, e2e tests, and finally `openapi:export` followed by `git diff --exit-code docs/api/openapi.v0.json`.

## Consequences
- A pull request is mergeable only when the whole suite is green against real Postgres, Redis and Mailpit (to enforce, make the `CI / test` check required on `main` in the repository settings).
- `pnpm lint` keeps `--fix` for local use; CI uses `pnpm lint:check`.
- Reproducing CI locally is the README's "Reproduce CI locally" block: the same commands on a fresh `docker compose` stack.
